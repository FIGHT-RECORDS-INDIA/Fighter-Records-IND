# Fighter-Records-IND

Independent Indian MMA fighter database starter website.

## Publish with GitHub Pages
1. Upload the contents of this folder to the repository root (not the enclosing folder).
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then Save.

## Important data note
This is an independent project, not an official UFC or federation database. Vaibhav Hase's 5-0-0 record is marked as fighter-supplied and not independently verified. Other profiles with missing records are placeholders; verify every record and event from reliable sources before publication. Rankings are intentionally not asserted without a transparent methodology.
